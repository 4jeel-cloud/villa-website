# Creek View Villa — Homestay Booking Website

A full-stack homestay booking system for Creek View Villa, Wayanad, Kerala.

## Stack

- **Frontend** — React 19, Vite, FullCalendar, Firebase Auth
- **Backend** — Node.js, Express, Nodemailer, Razorpay
- **Data** — Google Sheets via Apps Script

## Setup

### Backend
```bash
cd backend
npm install
cp .env.example .env   # fill in your values
node src/server.js
```

### Frontend
```bash
cd frontend
npm install
cp .env.example .env   # fill in your values
npm run dev
```

## Environment Variables

See `backend/.env.example` and `frontend/.env.example` for required variables.
